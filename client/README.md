# hyperspace-client

The Hyperspace client: the `hyperspace` CLI, the sync engine, and the harness
adapters.

```sh
uv tool install 'hyperspace-client @ git+https://github.com/wlritchi/hyperspace@client-vX.Y.Z#subdirectory=client'
```

Configure it in `$XDG_CONFIG_HOME/hyperspace/config.toml`, or with
`HYPERSPACE_URL` and `HYPERSPACE_TOKEN`. There is no default server URL.
