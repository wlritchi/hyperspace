Hyperspace {{ .Chart.AppVersion }} is installed as {{ include "hyperspace.fullname" . }}.

The chart makes no credentials. Make one for each host, inside the pod:

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "hyperspace.fullname" . }} -- \
    python /app/hyperspace/scripts/new-credential.py \
    --host <host name> --scopes append,read,grant --read all

Use --read all for workstations and --read granted for runners. The script
prints the token once. Revoke a credential with scripts/revoke-credential.py.
